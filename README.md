# natural-korean

![원고지 한 줄에 빨간 색연필로 줄을 긋고 고친 자리](assets/banner.webp)

**Opus 5.5 전용** 한글 윤문 스킬입니다. Opus 5.5가 쓴 한글, 또는 Opus 5.5로 고치는 한글에서 AI 티를 걷어냅니다.

파일 하나(`SKILL.md`)가 전부입니다. 스크립트를 돌리지 않고 에이전트도 부르지 않습니다. 글을 붙여넣으면 한 번에 고쳐서 돌려줍니다. 스킬 frontmatter에 `model: claude-opus-5-5`가 박혀 있어서, 세션 모델이 무엇이든 이 스킬이 도는 동안은 Opus 5.5로 바뀝니다.

## 왜 Opus 5.5 전용인가

이 스킬은 Opus 5.5에서만 제대로 동작합니다. "진정한", "비로소", 줄표 같은 뻔한 AI 표현은 Opus 5.5, Sonnet 5, Haiku 4.5 모두 스킬 없이도 잘 빼서 여기엔 스킬이 별로 필요 없습니다. 갈린 건 문장 길이였습니다. 문장 길이를 사람 글처럼 섞는 규칙을 주면 Opus 5.5는 변동계수가 0.38에서 0.64로 올랐고(사람 글 0.56), Sonnet과 Haiku는 거의 반응하지 않았습니다(Sonnet 0.32 → 0.39, Haiku 0.37 → 0.31, [evals/RESULTS.md](evals/RESULTS.md)).

Opus 5.5에는 따로 버릇이 있습니다. 고친 글을 브런치 출간 작가 글과 비교하면 아래 표현이 몇 배씩 더 나옵니다.

| Opus 5.5가 과하게 쓰는 표현 | 사람 (1,000자당) | Opus 5.5 |
|---|---|---|
| "A가 아니라 B", "A가 아니다. B다." | 0.6 | 2.5~5 |
| "~는데,"로 두 문장 잇기 | 0.8 | 2.5~4 |
| "~에 가깝다" | 0.05 | 0.5 |
| "~면 된다"로 처방하며 끝내기 | 0.02 | 0.5~1 |
| "눈여겨볼 만하다", "들러 볼 만하다" | 0 | 1 |

Opus 5.5 쪽 숫자는 아직 4,000자 정도에서 센 값이라 대략적입니다.

## 기준은 어디서 왔나

브런치(brunch.co.kr) '브런치 책방'의 출간 작가 100명에게서 최근 글 가운데 좋아요가 가장 많은 글을 한 편씩 모아 셌습니다. 모두 100편, 38만 자, 8,789문장입니다.

세어 보니 사람도 한 편에 한두 번씩 쓰는 말과, 사람은 거의 안 쓰는 말이 뚜렷하게 갈렸습니다.

| 출간 작가들도 쓰는 말 → 한 편에 한두 번으로 줄임 | 거의 안 쓰는 말 → 뺌 |
|---|---|
| 하지만 80편, 그리고 73편, 것이다 62편 | 여백 0편, 온도 3편, 여정 6편, 스며 6편 |
| 결국 50편, A가 아니라 B 52편(편당 1회꼴) | 진정한 7편, 비로소 8편, 결코 8편 |
| 에 대해 41편, 물론 41편 | 라는 점 5편, 라기보다 5편, 줄표(—) 4편 |

그 밖에 출간 작가들의 글에서 공통으로 보인 특징은 이렇습니다.

- 문장 길이 중앙값은 36자입니다. 그런데 열 문장 중 하나는 13자 이하이고, 하나는 76자 이상입니다.
- 한 문장짜리 문단이 42%입니다.
- 물음표는 1만 자당 12개로, 80편에서 썼습니다. 대사는 75편, 괄호 속 딴소리는 54편에서 나옵니다.
- 장면이나 짧은 선언으로 시작하는 글이 많고, 제목 구절을 본문에서 후렴처럼 되풀이합니다.
- 나열은 3개로 딱 맞추지 않고 2개로 끝내거나 5~6개를 쏟아냅니다.

좋아요 수가 곧 글의 품질은 아닙니다. 표본에는 수상 소감이나 강의 홍보 글도 10편 정도 섞여 있습니다.

## 설치

Claude Code에서:

```
/plugin marketplace add heyman333/natural-korean
/plugin install natural-korean@natural-korean
```

플러그인 없이 쓰려면 `SKILL.md`만 복사해도 됩니다.

```bash
mkdir -p ~/.claude/skills/natural-korean && curl -fsSL https://raw.githubusercontent.com/heyman333/natural-korean/main/skills/natural-korean/SKILL.md -o ~/.claude/skills/natural-korean/SKILL.md
```

## 사용

```
/natural-korean
(고칠 글 붙여넣기)
```

"AI 티 빼줘", "사람이 쓴 것처럼 고쳐줘", "윤문해줘"라고만 해도 동작합니다. 조직 정책으로 Opus 5.5를 쓸 수 없으면 현재 세션 모델로 돌아가는데, 그 경우 문장 길이 규칙은 거의 듣지 않습니다. 다른 윤문 스킬이 함께 깔려 있으면 어느 쪽이 실행될지 모르니 `/natural-korean`으로 직접 부르는 편이 확실합니다.

고친 뒤 "이 문단만", "더 세게", "더 가볍게"로 다시 요청할 수 있습니다.

## 예시

고치기 전:

> 퇴사 후 한 달, 나는 비로소 진정한 나 자신과 마주하게 되었다. 7년 동안 다닌 회사를 3월에 그만두었을 때, 솔직히 말하면 두려움이 컸다. 하지만 이 경험은 나에게 삶에 있어서 무엇이 중요한지를 깨닫게 해주었다.
>
> 가장 큰 변화는 아침 시간이다. 매일 아침 6시, 나는 한강을 따라 걷는다. 이 시간은 단순히 운동을 하는 시간이 아니라, 하루를 설계하고 생각을 정리하는 소중한 시간이 되어주었다.

고친 뒤:

> 퇴사한 지 한 달이 됐다. 요즘은 나에 대해 생각하는 시간이 부쩍 늘었다. 7년 다닌 회사를 3월에 그만둘 때는 겁이 많이 났다. 막상 나와 보니 뭐가 중요한지 조금은 알 것 같다.
>
> 제일 크게 바뀐 건 아침이다. 매일 아침 6시에 한강을 따라 걷는다. 운동 삼아 나간 건데, 걷다 보면 오늘 뭘 할지 정해지고 머릿속도 정리된다.

7년, 3월, 아침 6시, 한강은 그대로 남았습니다. 원문에 없는 내용은 지어내지 않고, 구체적으로 채우면 좋아질 자리는 글 뒤에 따로 적어 줍니다.

## eval

`evals/`에 AI 문체 샘플 5개, 브런치 실제 글 19편의 URL 목록, 채점기가 있습니다. 자세한 결과는 [evals/RESULTS.md](evals/RESULTS.md)에 있습니다.

```bash
evals/run.sh                                  # AI 문체 샘플 5개
python3 evals/fetch_brunch.py                 # 브런치 글 19편 받기 (저장소에는 URL만 있습니다)
python3 evals/score.py --brunch               # 브런치 결과 채점
```

브런치에 올라온 실제 글 19편으로 돌린 결과입니다(v0.5.1, Opus 5.5, 스킬은 3회 평균, 스킬 없음은 1회).

| | 스킬 없음 | 스킬 v0.5.1 | 원문 |
|---|---|---|---|
| AI 티 상위 14편: Opus 버릇 (1,000자당, 사람 1.5) | 2.5 | 1.0 | 3.0 |
| AI 티 상위 14편: 변경률 | 29% | 18% | |
| 사람 글 5편: 변경률 | 22% | 9% | |
| 사람 글 5편: 문장 길이 변동계수 | 0.56 | 0.60 | 0.60 |

스킬을 쓰면 덜 고치고도 AI 티는 더 많이 빠집니다. 잘 쓴 사람 글은 스킬 없이 고치면 22%가 바뀌고 문장 리듬이 고르게 눌리는데, 스킬을 쓰면 9%만 바뀌고, 세 번 중 두 번은 원문을 한 글자도 안 바꾼 글도 있었습니다. 소설은 문학 글로 알아보고 줄표, 말줄임, 은유를 그대로 둡니다. 브런치 소설 두 편은 1%만 고쳤습니다.

AI 문체 샘플 5개로 돌린 결과는 이렇습니다(2회).

| | 스킬 없음 | 스킬 v0.4 | 사람 글 |
|---|---|---|---|
| Opus 버릇 (1,000자당) | 5.9 | 2.2~2.7 | 1.5 |
| 문장 길이 변동계수 | 0.38 | 0.63~0.64 | 0.56 |
| 사실 보존 | 100% | 100% | |

## 기여

Opus 5.5가 고친 글에서 새 버릇을 찾으면 이슈나 PR로 알려주세요. 원문, Opus 5.5 출력, 그리고 가능하면 `python3 evals/score.py` 결과를 함께 주시면 표에 넣겠습니다.
