# natural-korean

Claude가 쓴 한글에서 AI 티를 걷어내는 Claude Code 스킬입니다.

파일 하나(`SKILL.md`)가 전부입니다. 스크립트를 돌리지 않고 에이전트도 부르지 않습니다. 글을 붙여넣으면 한 번에 고쳐서 돌려줍니다.

## 왜 만들었나

한글 윤문 스킬은 이미 여럿 있지만, 대부분 탐지, 윤문, 검증을 여러 번에 나눠 부릅니다. 그래서 느리고, 단계를 거칠수록 글이 다시 매끈해집니다.

이 스킬은 두 가지에 집중합니다.

- **Claude의 버릇.** 줄표(—), 본문 중간 굵은 글씨, "단순히 A가 아니라 B", "~라는 점에서", 결·온도·여백 같은 감성 추상어, 교훈으로 닫는 결말처럼 Claude가 한국어로 쓸 때 반복하는 패턴을 따로 모았습니다.
- **과보정 막기.** AI 티를 빼라고 하면 Claude는 짧은 문장만 늘어놓거나 "~것 같다"를 남발합니다. 이것도 막습니다.

규칙은 브런치(brunch.co.kr) 글 23편을 비교해서 잡았습니다. 사람이 쓴 것으로 읽히는 글은 문장 길이 편차가 크고(표준편차 33~37), 과거형 경험 서술과 대사, 숫자, 고유명사가 많았습니다. AI 티가 나는 글은 모든 문장이 비슷한 길이였고(표준편차 18), 현재형 일반론이 절반을 넘었으며, 대사가 하나도 없었습니다.

## 설치

Claude Code에서:

```
/plugin marketplace add heyman333/natural-korean
/plugin install natural-korean@natural-korean
```

플러그인 없이 쓰려면 `SKILL.md`만 복사해도 됩니다.

```bash
mkdir -p ~/.claude/skills/natural-korean && curl -fsSL https://raw.githubusercontent.com/heyman333/natural-korean/main/skills/natural-korean/SKILL.md -o ~/.claude/skills/natural-korean/SKILL.md
```

## 사용

```
/natural-korean
(고칠 글 붙여넣기)
```

"AI 티 빼줘", "사람이 쓴 것처럼 고쳐줘", "윤문해줘"라고만 해도 동작합니다. 다른 윤문 스킬이 함께 깔려 있으면 어느 쪽이 실행될지 모르니 `/natural-korean`으로 직접 부르는 편이 확실합니다.

고친 뒤 "이 문단만", "더 세게", "더 가볍게"로 다시 요청할 수 있습니다.

## 예시

고치기 전:

> 퇴사 후 한 달, 나는 비로소 진정한 나 자신과 마주하게 되었다. 7년 동안 다닌 회사를 3월에 그만두었을 때, 솔직히 말하면 두려움이 컸다. 하지만 이 경험은 나에게 삶에 있어서 무엇이 중요한지를 깨닫게 해주었다.
>
> 가장 큰 변화는 아침 시간이다. 매일 아침 6시, 나는 한강을 따라 걷는다. 이 시간은 단순히 운동을 하는 시간이 아니라, 하루를 설계하고 생각을 정리하는 소중한 시간이 되어주었다.

고친 뒤:

> 퇴사한 지 한 달이 됐다. 요즘은 나에 대해 생각하는 시간이 부쩍 늘었다. 7년 다닌 회사를 3월에 그만둘 때는 겁이 많이 났다. 막상 나와 보니 뭐가 중요한지 조금은 알 것 같다.
>
> 제일 크게 바뀐 건 아침이다. 매일 아침 6시에 한강을 따라 걷는다. 운동 삼아 나간 건데, 걷다 보면 오늘 뭘 할지 정해지고 머릿속도 정리된다.

7년, 3월, 아침 6시, 한강 같은 사실은 그대로 두고 문체만 바꿉니다. 원문에 없는 내용은 지어내지 않고, 구체적인 내용을 채우면 좋아질 자리는 글 뒤에 따로 알려줍니다.
